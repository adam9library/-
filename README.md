# مكتبة آدم — Android APK wrapper

هذا مشروع Android Studio جاهز لبناء APK من نسخة مكتبة آدم المنشورة على Abasthan.

- التطبيق يفتح: https://popularity-hot-penguin.abasthan.app/
- شاشة الدفع محذوفة من نسخة الموقع الجديدة.
- التطبيق يستخدم WebView مع JavaScript وLocal Storage حتى يعمل تسجيل الدخول والسلة بشكل طبيعي.

## بناء APK
افتح مجلد `android_app` في Android Studio، ثم اختر:
Build > Build APK(s)

الناتج عادةً يكون داخل:
`app/build/outputs/apk/debug/app-debug.apk`
